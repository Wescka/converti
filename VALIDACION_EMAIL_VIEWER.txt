DEPENDENCIA MSG
El soporte MSG usa extract-msg, una biblioteca diseñada para leer .MSG de Outlook sin Outlook.
Este entorno de validación no tenía extract-msg instalado y no tenía acceso de red para descargarlo,
por lo que no fue posible ejecutar aquí una prueba binaria real de MSG. La integración usa la API
openMsg(), attachments, htmlBody/body y propiedades estándar de extract-msg; requirements_email.txt
incluye la dependencia para instalarla en el servidor.
